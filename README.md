# MTG-ReprintGap

## 概要 (Overview)

MTG-ReprintGapは、Scryfallのバルクデータ（`default-cards.json`）を解析し、Magic: The Gathering (MTG) のカードが再録されるまでの最も長い空白期間（日数）を計算・抽出するPythonスクリプトです。

単に「初版から2回目の印刷」を測るのではなく、同一カードのすべての印刷履歴のタイムラインを網羅し、歴史上で「最も長い間、次の再録（印刷）まで放置されていた期間」を正確に算出します。

## 主な特徴 (Features)

* **トーナメント基準の厳密なフィルタリング:** 基本土地、トークン、アートカード、プロモ専用カードタイプ（コンスピラシーやアトラクション等）を網羅的に除外。
* **非公式カードの包括的除外:** 銀枠、金枠（世界選手権デッキ等）、どんぐりスタンプ（Unfinity）、プレイテストカード、大判カード、提示用統率者カード（thick）などのノイズを完全にシャットアウト。
* **日付単位のギャップ算出:** 同一日に発売された複数セット（通常セットと統率者デッキの同時発売など）による「0日ギャップ」の重複を自動排除。
* **Pandas高速化ロジック:** 膨大なバルクデータを高速に処理するため、ベクトル演算（groupby と shift）を用いた高効率な処理構造を採用。

## 動作環境 (Requirements)

* Python 3.x
* pandas

## 使い方 (Usage)

1. [Scryfall Bulk Data](https://scryfall.com/docs/api/bulk-data) ページから **Default Cards** のJSONファイルをダウンロードします。
2. ダウンロードしたJSONファイルを `main.py` と同じディレクトリに配置します。
3. `main.py` 内の以下の部分（ファイル名）を、ダウンロードしたファイル名に合わせて変更してください。

   ```python
   DATA_FILE = "default-cards-20260516091059.json"
   ```

4. 必要なライブラリ（`pandas`）をインストールしていない場合はインストールします。

   ```bash
   pip install pandas
   ```

5. スクリプトを実行します。

   ```bash
   python main.py
   ```

条件（デフォルトでは10,000日以上）に合致したカード、または指定された上位件数が日数降順・カード名昇順で標準出力されます。
